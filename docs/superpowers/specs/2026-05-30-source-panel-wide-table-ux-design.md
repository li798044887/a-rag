# 一次資料パネル: 横幅広表のUX改善 設計

## 背景 / 問題

一次資料パネル（`RightPanel`）で、列数の多い表を含むセクションを表示すると、
表がパネル右端からはみ出して列が途中で切れて見える。

- 表（`HtmlTable`）は既に `overflow-x-auto` を持ち、横スクロール自体は可能
  （`src/components/sources/html-table.tsx:35`）。
- しかしスクロール可能であることが伝わらない（macOS / タッチ環境ではスクロールバーが自動非表示）。
- パネル幅が固定: デスクトップは `420px` のグリッド列（`src/components/workspace/workspace.tsx:532`）、
  モバイルは `min(440px,92vw)` のオーバーレイ（`src/components/sources/right-panel.tsx:121`）で広げられない。

問題は2層: ① 横スクロール可能であることが伝わらない（全環境）、
② デスクトップでパネルが狭く広げられない（固定420px）。

## ゴール

全環境で「横に続きがある」と分かるようにし、デスクトップではパネルを広げられ、
モバイル/超幅広表では全画面で見られるようにする。表示や配色トークンは既存を踏襲する。

## 非ゴール

- 表の自動折り返し・列幅自動調整など、表レイアウトそのものの作り替えはしない。
- `構造化` / `元PDF` トグルや出典ハイライトの挙動は変更しない。

---

## パート1: 表のスクロール・アフォーダンス（全環境の土台）

対象: `src/components/sources/html-table.tsx`、新規フック。

- スクロールコンテナ（現状 `overflow-x-auto` の `div`）を `position: relative` のラッパで包む。
- スクロール位置を監視する小フック `useOverflow`（新規 `src/components/sources/use-overflow.ts` 程度）を追加。
  - `ref` の `scrollLeft` / `scrollWidth` / `clientWidth` を `scroll` と `ResizeObserver` で監視。
  - 続きがある側を示す真偽値 `{ left, right }` を返す。
- ラッパに `data-overflow-left` / `data-overflow-right` を付け、
  続きがある側だけ**端のグラデーション・フェード＋薄い影**をオーバーレイ表示、端まで来たら消す。
- 右フェード上に**小さなシェブロン（›）ヒント**を重ね、初見でも横スクロールに気づけるようにする。
- スクロールバーは細め（thin）かつ**常時可視**のスタイルにする（自動非表示対策）。

受け入れ基準:
- 幅広表で右端にフェード＋シェブロンが出る。右端までスクロールすると右フェードが消える。
- 表がパネル幅に収まる場合はフェードもシェブロンも出ない。

## パート2: デスクトップのパネル・リサイズ（ドラッグ境界）

対象: `src/components/workspace/workspace.tsx`。`wide` 表示（グリッド列）のときのみ有効。

- グリッドの `420px` 固定列を CSS 変数 `var(--rp-width)` に置き換える。
- パネル左境界に**ドラッグハンドル**を設置: 幅 4–6px、ホバーで色付く、`cursor: col-resize`。
- 幅を**クランプ**: 最小 `360px` 〜 最大 `min(720px, 50vw)`。
- 幅を **localStorage に永続化**（キー例: `arag.rp-width`）。
- ハンドル**ダブルクリックで既定幅（420px）にリセット**。
- アクセシビリティ: ハンドルに `role="separator"`、`aria-orientation="vertical"`、
  キーボード ←/→ で増減（一定ステップ、Shift で大ステップ）。
- オーバーレイ（モバイル/`max-wide`）表示時はハンドルを出さない。

受け入れ基準:
- デスクトップでハンドルをドラッグするとパネル幅がクランプ範囲で変わる。
- リロード後も幅が保持される。ダブルクリックで420pxに戻る。
- キーボードでも幅を変えられる。

## パート3: モバイル / 超幅広表の全画面拡大

対象: `src/components/sources/html-table.tsx` ＋ 全画面シート用の小コンポーネント。

- 表がはみ出していると検出した（パート1の `right` が真になりうる）ときだけ、
  表の右上に**「⤢ 拡大」ボタン**を表示。
- タップで**全画面シート（モーダル/シート）**を開き、表だけを広い領域で自由にスクロール閲覧できる。
- デスクトップでも超幅広表に有効（幅を伸ばしきれないケースの逃げ道）。
- シートは Esc / 背景タップ / 閉じるボタンで閉じる。

受け入れ基準:
- 幅広表にのみ拡大ボタンが出る。収まる表には出ない。
- ボタンで全画面シートが開き、表を全体スクロールできて閉じられる。

## 影響ファイル

- `src/components/sources/html-table.tsx` — パート1（アフォーダンス）、パート3（拡大ボタン＋シート起動）。
- `src/components/sources/use-overflow.ts`（新規）— オーバーフロー検出フック。
- 全画面シート用の小コンポーネント（新規、`html-table.tsx` 近傍）。
- `src/components/workspace/workspace.tsx` — パート2（可変グリッド＋ドラッグハンドル＋永続化）。
- 配色トークン（`divider`, `surface` 等）と既存の Story 構成はそのまま流用。

## リスク / 留意点

- グリッド列を CSS 変数化する際、既存の `wide:data-[rp=open]:grid-cols-[...]` バリアントとの
  整合を保つ（`420px` 直書き箇所を変数へ集約）。
- `ResizeObserver` / `scroll` 監視はパネル開閉・タブ切替・PDF/構造化トグルでも再計測されること。
- ドラッグ中のテキスト選択抑止（`user-select: none`）とポインタキャプチャ。
