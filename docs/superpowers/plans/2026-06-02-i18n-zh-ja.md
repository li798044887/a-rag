# 中日双语支持（i18n）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为应用增加中文（默认）/ 日语双语支持：界面文案全量本地化、RAG 系统提示词按语言动态切换、设置内手动切换并刷新页面、偏好存 Cookie。

**Architecture:** 自建轻量 i18n（`src/i18n/`）：服务端 `getLocale()` 读 `arag_locale` Cookie，`layout.tsx` 注入 `LocaleProvider`；组件经 `useT()` 取词典。词典按功能命名空间拆分（`locales/zh/<ns>.ts`、`locales/ja/<ns>.ts`），`ja` 用显式类型注解与 `zh` 强制键对等。RAG prompt 集中到 `src/lib/agent/prompts.ts` 的 `getAgentPrompts(locale)`，`chat/route.ts` 读 locale 传入。切换写 Cookie + `location.reload()`。

**Tech Stack:** Next.js 16（App Router，`cookies()` 为 async）、React 19、TypeScript、Vitest（unit）、Playwright（e2e）、Tailwind v4。

**对应设计书：** `docs/superpowers/specs/2026-06-02-i18n-zh-ja-design.md`

**约定：**
- 词典值一律为**纯字符串**（不用 `as const`、不放函数）；需要插值的用 `{var}` 占位符 + `interpolate()`。
- `zh` 为唯一事实来源；`ja` 文件用 `: typeof zhX` / `: Dictionary` 显式注解，缺键或多键编译期报错。
- **只替换用户可见字面量；日语代码注释一律保留不动。**
- 每个任务结束 `pnpm test`（unit）须绿；提交信息用日语 Conventional Commits。
- 新添加的代码需保持使用日语注释

```ts
/** サポートする UI/プロンプト言語。zh が既定。 */
export type Locale = "zh" | "ja";

export const LOCALES: Locale[] = ["zh", "ja"];
export const DEFAULT_LOCALE: Locale = "zh";

/** 言語設定の保存先 Cookie 名（クライアント書き込み・サーバ読み取り）。 */

export function isLocale(value: unknown): value is Locale {
  return value === "zh" || value === "ja";
}

/** <html lang> 用の BCP47 タグ。 */
export function htmlLang(locale: Locale): string {
  return locale === "zh" ? "zh-CN" : "ja";
}
```

```ts
// src/i18n/interpolate.ts
/** 辞書文字列中の {var} を vars で置換する。vars 省略時はそのまま返す。
 *  欠落キーは {key} を残す（翻訳漏れの可視化のため）。 */
export function interpolate(template: string, vars?: Record<string, string | number>): string {
  if (!vars) return template;
  return template.replace(/\{(\w+)\}/g, (_, key: string) =>
    key in vars ? String(vars[key]) : `{${key}}`,
  );
}
```

```ts
function keyPaths(obj: Record<string, unknown>, prefix = ""): string[] {
  return Object.entries(obj).flatMap(([k, v]) => {
```

```ts
// src/i18n/server.ts
import "server-only";
import { cookies } from "next/headers";
import { LOCALE_COOKIE, DEFAULT_LOCALE, isLocale, type Locale } from "./config";

/** リクエストの Cookie から言語を解決する。未設定/不正は既定 zh。 */
export async function getLocale(): Promise<Locale> {
  const jar = await cookies();
  const value = jar.get(LOCALE_COOKIE)?.value;
  return isLocale(value) ? value : DEFAULT_LOCALE;
}
```

```tsx
// src/i18n/context.tsx
"use client";

import { createContext, useContext } from "react";
import type { Locale } from "./config";
import type { Dictionary } from "./dictionary";

interface LocaleContextValue {
  locale: Locale;
  /** 解決済み辞書。t.common.cancel のように参照する。 */
  t: Dictionary;
}

const LocaleContext = createContext<LocaleContextValue | null>(null);

export function LocaleProvider({
  locale,
  dict,
  children,
}: {
  locale: Locale;
  dict: Dictionary;
  children: React.ReactNode;
}) {
  return (
    <LocaleContext.Provider value={{ locale, t: dict }}>
      {children}
    </LocaleContext.Provider>
  );
}

export function useT(): LocaleContextValue {
  const value = useContext(LocaleContext);
  if (!value) throw new Error("useT must be used within LocaleProvider");
  return value;
}
```

```ts
function stageToEvent(ev: RetrieveStageEvent, parentId: string, query: string, prompts: AgentPrompts): AgentEvent {
  const stageKey = ev.stage as keyof AgentPrompts["stageLabels"];
  const base = {
    id: `${parentId}:${ev.stage}`,
    name: ev.stage as ToolName,
    parentId,
    label: prompts.stageLabels[stageKey] ?? ev.stage,
  };
  if (ev.status === "start") {
    return { type: "step", step: { ...base, status: "running", durationMs: 0, input: {}, output: null, summary: prompts.stageRunning[stageKey] ?? prompts.stageDefaultRunning } };
  }
  if (ev.status === "error") {
    return { type: "step", step: { ...base, status: "error", durationMs: ev.ms ?? 0, input: {}, output: { error: ev.message ?? prompts.stageErrorSummary }, summary: prompts.stageErrorSummary } };
  }
  return { type: "step", step: { ...base, status: "done", durationMs: ev.ms ?? 0, input: stageInput(ev, query), output: stageOutput(ev), summary: stageDoneSummaryOf(prompts, ev.stage, ev.count) } };
}
```

```ts
// src/i18n/use-locale-switch.ts
import { buildLocaleCookie } from "./cookie";
import type { Locale } from "./config";

export interface LocaleSwitchEffects {
  setCookie: (value: string) => void;
  reload: () => void;
}

/** Cookie 書き込み → リロード。副作用は注入してテスト可能にする。 */
export function performLocaleSwitch(next: Locale, effects: LocaleSwitchEffects): void {
  effects.setCookie(buildLocaleCookie(next));
  effects.reload();
}

/** ブラウザ既定の副作用。 */
export const browserLocaleEffects: LocaleSwitchEffects = {
  setCookie: (value) => { document.cookie = value; },
  reload: () => { window.location.reload(); },
};
```

## Phase 4 — 界面文案按命名空间迁移

### 命名空间迁移规程（所有 Task 12–20 通用）

每个命名空间任务对一组组件执行**相同的 5 步**。下面给出**完整范例**（以 `chat/empty-state.tsx` 为例），后续任务只需替换「文件清单」「字符串清单」，照此规程操作。

**规程：**
1. **新建 zh 命名空间文件** `src/i18n/locales/zh/<ns>.ts`：把目标组件里**用户可见的日语字面量**抽成键，值写**新的中文译文**（非机翻，符合语境）。需插值的用 `{var}`。
2. **新建 ja 命名空间文件** `src/i18n/locales/ja/<ns>.ts`：`import { <ns> as zh<Ns> } from "../zh/<ns>";` 并 `export const <ns>: typeof zh<Ns> = { ... }`，值=**组件里原有的日语原文**。
3. **登记到聚合**：在 `zh/index.ts` 与 `ja/index.ts` 各 import 并加入聚合对象（两边都加，键名一致）。
4. **改组件**：`import { useT } from "@/i18n/context";`，组件内 `const { t } = useT();`（含计数/插值处 `import { interpolate } from "@/i18n/interpolate";`），把字面量替换为 `t.<ns>.<key>`；`toLocaleString("ja-JP")` 改为 `toLocaleString(locale === "zh" ? "zh-CN" : "ja-JP")`（locale 来自 `useT()`）。
5. **跑 parity 测试 + 提交**：`pnpm test src/i18n/dictionary.test.ts`（键对等自动校验），再 `pnpm exec tsc --noEmit`。

**完整范例（chat 命名空间起步，含 empty-state）：**


`src/i18n/locales/ja/chat.ts`（对应日语原文）：

`empty-state.tsx` 改造要点：
```tsx
import { useT } from "@/i18n/context";
import { interpolate } from "@/i18n/interpolate";
// greeting() 改为接收 t：
function greeting(t: ReturnType<typeof useT>["t"]) {
  const h = new Date().getHours();
  if (h < 11) return t.chat.greetingMorning;
  if (h < 18) return t.chat.greetingDay;
  return t.chat.greetingEvening;
}
// 组件内：
const { t, locale } = useT();
const meta = [
  [stats.indexedDocumentCount.toLocaleString(locale === "zh" ? "zh-CN" : "ja-JP"), t.chat.metaIndexed],
  [stats.connectedDataSourceCount.toLocaleString(locale === "zh" ? "zh-CN" : "ja-JP"), t.chat.metaConnected],
  [t.chat.metaLastSync, formatLastSynced(stats.lastSyncedAt)],
];
// 标题：
<h1 ...>{interpolate(t.chat.greetingName, { greeting: greeting(t), name: user.firstName, suffix: t.chat.greetingSuffix })}</h1>
// 引导语：
<p ...>{t.chat.emptyLead}</p>
```
